Brainrot Bazaar is a 3D Roblox brainrot tycoon game. Absurd meme characters parade down a conveyor lane; you catch the ones you can afford, carry them home to your base where each one earns cash every second, climb a ladder of rarities and mutations, rebirth for a permanent multiplier — and when the tsunami alarm sounds, drop everything and dash home before the wave sweeps your catch away.

## Run it

```sh
rojo build default.project.json --output game.rbxl && mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
